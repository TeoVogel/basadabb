# Map with Leaflet and OpenStreetMap, link out to Google Maps

The map is drawn with Leaflet and OpenStreetMap tiles, not with the Google Maps JavaScript API. Every Google Maps Platform API needs a billing account with a card on file and a public key, which is at odds with the project's zero-cost constraint. Google Maps is still the place visitors end up: each Local's "Abrir en Google Maps" button is a plain Google Maps URL, which needs no API.
